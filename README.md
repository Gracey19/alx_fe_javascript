# Dynamic Quote Generator

This project is part of the ALX Front-End curriculum, focusing on advanced DOM manipulation using vanilla JavaScript. It demonstrates how to dynamically create, update, and manage content on a webpage based on user interactions—without relying on external libraries or frameworks.

##Project Overview

The **Dynamic Quote Generator** allows users to:
- View a random quote from a predefined list
- Add new quotes and categories through a form
- See the updated quote instantly on the page

All DOM elements are generated and updated using JavaScript, showcasing core front-end skills.

##Technologies Used

- HTML5
- CSS3 (optional styling)
- JavaScript (ES6+)
